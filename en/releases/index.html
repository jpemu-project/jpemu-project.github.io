RELEASE NOTES

Release notes

What changed in JPEmu Renamer, newest version first. The latest version is available from Download on the home page.

1.5.1 2026.11.22

A bug-fix release for carrying the app folder around, for example on a USB drive.

BUG FIXES

  • Fixed undo discarding the records of files it could not revert. They are now kept for a later retry, and they no longer block undoing other runs.
  • Fixed saved folder locations sometimes being rewritten to another drive when an external drive was disconnected at startup.
  • Fixed every ROM being read again after moving the app folder or when the USB drive letter changed.
  • Rename records for files inside the app folder are now portable, so undo still works after moving the folder.
  • Fixed typed relative paths sometimes pointing to the wrong place until restart.
  • Fixed folders whose names start with ".." (such as ..roms) being treated as outside the app folder.
  • Fixed a damaged rename history being overwritten without a backup (a copy is now saved as history.json.broken).

UI CHANGES

  • A mark (✓ / △) under the location fields shows whether the folder can be carried along with the app.

1.5.0 2026.11.21

Now 105 supported systems, and a new app icon.

NEW SYSTEMS

  • 50 systems added (105 in total): 3D systems such as PlayStation 2, GameCube, Wii, Dreamcast, PSP and NUON; consoles and handhelds such as Neo Geo CD, 64DD, CD-i, Amiga CD32, Tamagotchi, Game & Watch, PICO-8 and CHIP-8; and computers such as FM Towns, Atari ST, Macintosh, MS-DOS, Apple II and BBC Micro.
  • The 3D systems need graphics that support OpenGL 3.3 or later. The parts used by the PSP, GameCube, Wii and PS2 cores are downloaded automatically the first time you launch them.

NEW FEATURES

  • Mouse support. On Amiga, X68000, PC-9801, FM Towns, Atari ST, Macintosh and MS-DOS, click the game screen to use the mouse in the game.
  • The official libretro core information is now built in, so BIOS hints are more accurate and even systems you create yourself get a core that matches the file extension.

UI CHANGES

  • A new app icon: a white handheld console. The same icon appears in the title bar.

BUG FIXES

  • Fixed the hints about where to put the BIOS for FM Towns and CD-i.
  • For systems that need a BIOS, the missing files are now shown before launching.

1.4.0 2026.11.20

Now 55 supported systems, with the keyboard passed straight through on computer systems.

NEW SYSTEMS

  • 10 systems added (55 in total): MSX, MSX2, PC-8801, PC-9801, X68000, X1, ZX Spectrum, Commodore 64, Amiga and Amstrad CPC.

NEW FEATURES

  • On computer systems, the keyboard is now sent straight to the game (menu with F12, full screen with F11).
  • Games with two or more discs can swap discs from "Change disc" in the in-game menu (.m3u is supported).

UI CHANGES

  • Recessed areas (the game list, info card and so on) now have a shadow just inside their edges, for a more three-dimensional look.

1.3.0 2026.11.19

A new look.

UI CHANGES

  • A fresh "soft UI" look with gentle raised and pressed shadows, in all six themes.
  • The Light, Dark, Aqua, Metal, Pink and Chic themes have new colors. Switch them in Settings as before.
  • The selected system and game now stand out clearly.
  • The game list keeps a divider line between games.
  • Buttons, toggles, text boxes, check boxes, sliders and scroll bars share the new design.

1.2.0 2026.11.17

Now 45 supported systems.

NEW SYSTEMS

  • 18 systems added (45 in total): Satellaview, Pokémon mini, Sega Pico, PC-FX, Super Cassette Vision, 3DO, Atari 2600 / 5200 / 7800 / Lynx / Jaguar, ColecoVision, Intellivision, Vectrex, Odyssey² / Videopac, Channel F, Mega Duck and Supervision.
  • Built-in cores are picked automatically when you choose a system. For systems that need a BIOS, the missing file names are shown.

NEW FEATURE

  • DATs in clrmamepro format, such as No-Intro and Redump (XML or text), now work as they are, even inside a ZIP. Region names like (Japan) and (USA) show as flags.

1.1.5 2026.11.17

UI CHANGES

  • Systems with no missing games (complete sets) show a small crown at the top right of their icon in the left list.

1.1.4 2026.11.11

BUG FIXES

  • Fixed a problem where the right core and BIOS hints did not appear when a system name was written slightly differently from the presets (full-width characters, spaces, "CD-ROM2" vs "CD-ROM²", and so on).

1.1.3 2026.11.09

UI CHANGES

  • The selected system in the left list now has a stronger background and an accent mark, so it is easier to see.
  • The selected system's name and its owned / missing counts appear above the list (hidden when the window is narrow).

1.1.2 2026.11.09

Bug fixes and faster loading.

FASTER

  • Opening a system is much faster (for example, Nintendo DS went from about 8 seconds to about 0.2 seconds, from the second launch on).
  • The window no longer freezes when you open a system for the first time.

BUG FIXES

  • Fixed counts staying blank in the left list when you switched systems while one was still loading.
  • Fixed loading progress not showing when you selected a system that was still loading in the background.

1.1.1 2026.11.08

Now portable: carry the whole folder on a USB drive.

CHANGES

  • Settings, cores, saves, screenshots and more are now kept in a data folder next to the exe.
  • Locations inside the app folder (ROMs, DATs, BIOS and so on) are stored as relative paths, so a changed drive letter does not matter.
  • Settings from 1.1.0 and earlier are carried over automatically on first launch.

1.1.0 2026.11.08

UI updates and bug fixes.

UI CHANGES

  • Script-style title in the header and on the preview screen.
  • The TV-style preview is about 1.3 times larger.
  • New Sort button: release date, title, publisher, genre, price and status.
  • Filters are now All / Owned / Missing, and missing rows also show their titles.
  • Owned / missing counts for every system are shown at startup.
  • The status bar now reads Owned / To rename / Missing.
  • The publisher column adapts to the window width.

NEW SYSTEMS

  • Nintendo 3DS, Nintendo DSiWare, Super 32X and PC Engine SuperGrafx.

BUG FIXES

  • Fixed the select-all checkbox on the Rename tab not working.
  • Fixed duplicate files being left behind instead of moved.
  • Fixed demos playing for games you had not selected, at startup and when switching systems.
  • Fixed file extensions not showing after turning off "Hide file extensions".
  • Fixed a disabled "Game" button appearing in play settings opened without a game.
  • When a BIOS is missing, the file name and where to put it are now shown.

1.0.0 2026.11.04

The first public release.

  • Rename with No-Intro / OfflineList DATs matched by CRC32. Every run is logged and can be undone.
  • Built-in libretro cores, the same as RetroArch.
  • TV-style auto preview, region flags, 6 themes and 16 languages.
