How to Use the Japanese Title DAT Files

We publish DAT files for free, with Japanese titles, release dates, prices and genres for games released in Japan. Use them when you want your ROM file names to be the official Japanese titles.

What these DATs are

  • They are OfflineList-format DATs. They work with JPEmu Renamer and OfflineList.
  • Titles follow the spelling on the makers' official websites. Where there is none, they follow the "game title list" on Japanese Wikipedia.
  • Characters that Windows cannot use in file names (\ / : * ? " < > |) are replaced with full-width look-alikes.
  • No ROMs or BIOS files are included. It is only a list of names.

Supported systems

Famicom, Famicom Disk System, Super Famicom, Game Boy, Game Boy Color, Game Boy Advance, Virtual Boy, Nintendo 64, Nintendo 3DS, SG-1000, Master System, Mega Drive, Super 32X, Game Gear, Mega-CD, Sega Saturn, PC Engine (including SuperGrafx and CD-ROM²), Neo Geo, Neo Geo Pocket, Neo Geo Pocket Color, WonderSwan and WonderSwan Color.

More systems are added over time. The latest list of systems and the number of titles is in the README.txt inside the ZIP.

How to use them

  1. Download the DATsFrom "DAT files (Japanese)" in the download section, download the ZIP file and extract it.
  2. Pick the file for your systemThe file names look like JP_English system name.xml (for example, JP_Super Famicom.xml is for the Super Famicom). There is one file per system.
  3. Set the DAT in System settingsOpen "System settings" in JPEmu Renamer and set that system's DAT as the "DAT file". If you also set the ROM folder, matching starts automatically.
  4. RenameOn the "Rename" tab, check the current name and the name in the DAT, then press "Rename". For the details, see How to Rename ROMs Correctly with a DAT File.

Good to know

  • They cover titles released in Japan. ROMs of overseas releases are not in the DAT, so they show as "Not in DAT".
  • File names become Japanese. Windows Explorer handles them without problems. If you would rather keep your file names, turn on "Show DAT names only" in "System settings". The files keep their names, and only the list in the app shows the Japanese titles.
  • You can undo. After renaming, "Undo" reverts the whole run.
  • Please use ROMs that you dumped yourself.

If you find a mistake in a DAT, please let us know on GitHub.
