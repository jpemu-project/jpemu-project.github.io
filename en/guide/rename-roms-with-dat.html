How to Rename ROMs Correctly with a DAT File

Rename ROMs with messy file names to the correct titles in one go, by matching their contents (CRC32) against a DAT file. You can review everything before it runs, and undo it afterwards.

What are a DAT and CRC32?

A DAT is a list (an XML file) of game titles and their CRC32 values. CRC32 is a fingerprint-like value calculated from the contents of a file.

JPEmu Renamer calculates the CRC32 of each ROM and compares it with the values in the DAT. No matter how messy the file name is, if the contents are the same, the title is recognized correctly. Only files that match are renamed to the name written in the DAT.

What you need

  • JPEmu Renamer (free, Windows 10 / 11 64-bit, no installation). Download it here
  • ROMs that you dumped yourself
  • A DAT file for each system (OfflineList-format XML). Older Shift-JIS DATs are supported too. DATs with Japanese titles for games released in Japan are available for free here

No ROM or BIOS files are distributed on this site.

Steps

  1. Add a systemUse "+ Add system" at the bottom left. If you choose a preset, the extensions, icon, color and built-in core are filled in for you.
  2. Set the DAT file and the ROM folderIn "System settings", set the DAT file, the ROM folder (separate several with ;) and the extensions to read (for example .nes;.zip). Once set, the ROMs are read and matched automatically. From the second time on, unchanged files are skipped, so it finishes quickly.
  3. Check the result on the Rename tabSwitch to the "Rename" tab at the top. The current file name and the name in the DAT are shown side by side.
  4. Run the renameLook at the rows marked "Rename". Uncheck any row you do not want to rename. The right side shows "Before" and "After" for the selected row. When it looks right, press "Rename" at the bottom and choose "Yes" in the confirmation.
  5. Undo if you change your mind"Undo" on the Rename tab reverts the last run completely. Press it again to revert the run before that (up to the last 50 runs).

What the statuses mean

StatusMeaningRenamed?
MatchThe CRC32 matches and the name is already the same as the DAT.No need
RenameThe CRC32 matches but the name differs from the DAT.Yes
DuplicateA file for the same title already exists.No
Not in DATThe CRC32 is not in the DAT.No
MissingIt is in the DAT, but you do not have the file.-

Files marked "Duplicate" or "Not in DAT" can be moved to a folder you choose, to tidy things up. Filtering the list to "Missing" shows the titles you do not have yet.

Good to know

  • ROM names inside ZIP files can be renamed too. Turn on "Settings" → "Also rename the ROM inside ZIP files", and the ROM inside each ZIP is renamed along with the ZIP file itself.
  • Characters Windows cannot use are replaced automatically. \ / : * ? " < > | become full-width look-alikes.
  • If you would rather not change file names. For systems like arcade, where renaming a file can stop the emulator from working, there is a "Show DAT names only" option. Turn it on in "System settings" to keep the file names as they are and show the DAT names only in the list.

If something goes wrong

ProblemWhat to check
Zero matchesCheck that the DAT is for the same system as the ROMs. Changing "Header handling" to "Include" or "Exclude" can make them match (for example iNES headers on Famicom / NES ROMs).
The DAT cannot be readCheck that it is an OfflineList-format (XML) DAT.
"Duplicate"You have two or more ROMs for the same title. Move one of them to another folder.
Skipped with "(exists)"A file with the new name already exists. Decide which one to keep, then tidy up by hand.
