RELEASE NOTES

リリースノート

JPEmu Renamer の変更点です。新しいバージョンから順に載せています。最新版は、トップページの「ダウンロード」から入手できます。

1.5.1 2026.11.22

フォルダごと持ち運ぶとき（USBメモリなど）の不具合を直した、バグ修正版です。

バグ修正

  • 「元に戻す」に失敗したファイルの記録が消えてしまう不具合を直しました。戻せなかった分は記録に残り、あとで戻せます。戻せない記録が残っていても、戻せる別の回は戻せます。
  • 外付けドライブを外して起動すると、登録したフォルダの場所が別のドライブに書き換わることがある不具合を直しました。
  • アプリのフォルダを移動したり、USBメモリのドライブ文字が変わったりすると、すべてのROMを読み直していた不具合を直しました。
  • アプリのフォルダの中でリネームした記録も持ち運べるようにし、移動したあとでも「元に戻す」が使えるようにしました。
  • 手で入力した相対パスが、再起動するまで違う場所を指すことがある不具合を直しました。
  • 「..roms」のように「..」で始まる名前のフォルダが、アプリのフォルダの外として扱われる不具合を直しました。
  • 壊れたリネームの記録が、控えを残さずに上書きされる不具合を直しました（history.json.broken に控えを残します）。

UIの変更

  • 場所の欄の下に、フォルダごと持ち運べるかどうかの印（✓ / △）を表示します。

1.5.0 2026.11.21

対応機種が 105 機種になりました。アイコンも新しくなりました。

機種の追加

  • 50機種を追加（全105機種）。プレイステーション2、ゲームキューブ、Wii、ドリームキャスト、PSP、NUON などの3Dの機種のほか、ネオジオCD、64DD、CD-i、Amiga CD32、たまごっち、ゲーム&ウオッチ、PICO-8、CHIP-8 などのゲーム機・携帯機、FM TOWNS、Atari ST、マッキントッシュ、MS-DOS、Apple II、BBC Micro などのパソコンです。
  • 3Dの機種を遊ぶには、OpenGL 3.3 以上に対応したグラフィックスが必要です。PSP・ゲームキューブ・Wii・PS2 のコアが使う部品は、初めて起動するときに自動でダウンロードします。

機能の追加

  • マウスに対応しました。Amiga・X68000・PC-9801・FM TOWNS・Atari ST・マッキントッシュ・MS-DOS では、ゲーム画面をクリックすると、マウスをゲームで使えます。
  • libretro 公式のコアの情報を取り込みました。BIOS の説明が正確になり、自分で作った機種でも、拡張子に合うコアを選べます。

UIの変更

  • アプリのアイコンを、白い携帯ゲーム機の新しいものにしました。タイトルバーにも、同じアイコンが出ます。

バグ修正

  • FM TOWNS と CD-i の、BIOS の置き場所の説明を直しました。
  • 必要な BIOS が無い機種では、起動する前に、足りないファイルを知らせるようにしました。

1.4.0 2026.11.20

対応機種が 55 機種になりました。パソコン系の機種で、キーボードがそのまま使えます。

機種の追加

  • 10機種を追加（全55機種）：MSX、MSX2、PC-8801、PC-9801、X68000、X1、ZX Spectrum、コモドール64、Amiga、Amstrad CPC。

機能の追加

  • パソコン系の機種で、キーボードをそのままゲームに送れるようにしました（メニューは F12、全画面は F11）。
  • ディスクが2枚以上のゲームは、プレイ中のメニューの「ディスクを入れ替える」で入れ替えられます（.m3u に対応）。

UIの変更

  • へこんだ部分（ゲーム一覧・情報カードなど）のふちの内側に影を付けて、より立体的にしました。

1.3.0 2026.11.19

見た目を新しくしました。

UIの変更

  • 全体の見た目を、やわらかい影で浮き上がる「ソフトUI」に一新しました（6つのテーマすべて）。
  • テーマ（ライト・ダーク・アクア・メタル・ピンク・シック）を、新しい色で作り直しました。これまでどおり「設定」で切り替えられます。
  • 選んでいる機種やゲームが、へこみ・浮き上がりでひと目で分かるようにしました。
  • ゲーム一覧は、ゲームごとに線で区切って見やすくしました。
  • ボタン・切り替え・入力欄・チェックボックス・スライダー・スクロールバーも、同じデザインにそろえました。

1.2.0 2026.11.17

対応機種が 45 機種になりました。

機種の追加

  • 18機種を追加（全45機種）：サテラビュー、ポケモンミニ、キッズコンピュータ ピコ、PC-FX、スーパーカセットビジョン、3DO、アタリ 2600 / 5200 / 7800 / リンクス / ジャガー、コレコビジョン、インテレビジョン、ベクトレックス、オデッセイ²、チャンネルF、メガダック、スーパービジョン。
  • 機種を選ぶと、内蔵コアが自動で候補に入ります。BIOS が必要な機種では、足りないファイル名を案内します。

機能の追加

  • No-Intro・Redump などの形式（clrmamepro 形式）のDAT（XML・テキスト）を、そのまま使えるようにしました。ZIPに入ったままでも読めます。名前の地域（Japan / USA など）から、国旗も表示します。

1.1.5 2026.11.17

UIの変更

  • 未所有が0本の機種（コンプリートした機種）は、左の機種一覧のアイコンの右上に、小さな王冠を表示します。

1.1.4 2026.11.11

バグ修正

  • 機種名の書き方が候補と少し違うと（全角・半角、空白の有無、「CD-ROM2」と「CD-ROM²」など）、内蔵コアやBIOSの案内が正しく出ないことがある問題を直しました。

1.1.3 2026.11.09

UIの変更

  • 左の機種一覧で、選んでいる機種を、濃い背景と左の印で分かりやすく表示します。
  • 一覧の上に、選んでいる機種の名前と、所有／未所有の本数を表示します（ウィンドウが狭いときは表示しません）。

1.1.2 2026.11.09

バグ修正と高速化です。

高速化

  • 機種を開くときの待ち時間を短くしました（例：ニンテンドーDSは約8秒から約0.2秒に。2回目以降の起動）。
  • 初めて開く機種でも、画面が止まらなくなりました。

バグ修正

  • 読み込み中に別の機種を選ぶと、前の機種の本数が出ないままになる問題を直しました。
  • 裏で読み込みが続いている機種を選んだとき、進み具合が表示されなかった問題を直しました。

1.1.1 2026.11.08

ポータブル版になりました。フォルダごとUSBメモリなどに入れて持ち運べます。

変更

  • 設定・コア・セーブ・スクリーンショットなどを、exe と同じフォルダの data に保存します。
  • exe のフォルダの中にあるROM・DAT・BIOSなどの場所は、相対パスで保存します。ドライブ文字が変わっても、そのまま使えます。
  • 1.1.0 までの設定は、初めて起動したときに自動で引き継ぎます。

1.1.0 2026.11.08

UIの一部変更とバグ修正です。

UIの変更

  • ヘッダーのタイトルとプレビュー画面のロゴを、筆記体に変更しました。
  • テレビ風のプレビュー画面を、約1.3倍に広げました。
  • 一覧に「並び替え」ボタンを追加しました（発売日・タイトル・メーカー・ジャンル・価格・状態）。
  • 絞り込みを「すべて／所有のみ／未所有のみ」の順にし、未所有の行にもタイトルを表示します。
  • 起動時に、選んでいない機種の所有／未所有の数も表示します。
  • 状態表示を「所有／リネーム／未所有」に変えました。
  • メーカー欄の幅を、ウィンドウに合わせて調整します。

機種の追加

  • ニンテンドー3DS、ニンテンドーDSiウェア、スーパー32X、PCエンジン スーパーグラフィックス。

バグ修正

  • リネーム画面の全選択チェックボックスが効かない問題を直しました。
  • 重複ファイルが移動されずに残る問題を直しました。
  • 起動時や機種の切り替え時に、選んでいないゲームのデモが流れる問題を直しました。
  • 「拡張子を表示しない」をオフにしても、拡張子が表示されない問題を直しました。
  • ゲームを選ばずに開いたプレイ設定に、使えない「ゲーム」ボタンが出る問題を直しました。
  • BIOSが無いときに、足りないファイル名と置き場所を案内するようにしました。

1.0.0 2026.11.04

最初の公開版です。

  • No-Intro / OfflineList のDATをCRC32で照合してリネーム。実行ごとに履歴が残り、「元に戻す」で戻せます。
  • RetroArch と同じ libretro コアを内蔵。
  • テレビ風の自動プレビュー、国旗の表示、6テーマ・16言語に対応。

JPEmu Renamer をためす

無料・インストール不要。Windows 10 / 11（64bit）で動きます。
